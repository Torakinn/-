┌────────────────────────────────────────────────────────────────────┐
│  方法1: Git Clone（最も簡単！）⭐                                     │
└────────────────────────────────────────────────────────────────────┘

  ステップ1: ターミナルを開く
  ┌──────────────────────────────────────────┐
  │ $ cd resources/[qb]                      │
  └──────────────────────────────────────────┘

  ステップ2: クローンを実行
  ┌──────────────────────────────────────────────────────────────┐
  │ $ git clone https://github.com/Torakinn/- cayoperico-temp  │
  └──────────────────────────────────────────────────────────────┘

  ステップ3: フォルダをコピー
  ┌──────────────────────────────────────────┐
  │ $ cp -r cayoperico-temp/qb-cayoperico ./ │
  └──────────────────────────────────────────┘

  ステップ4: 一時フォルダを削除
  ┌──────────────────────────────────────────┐
  │ $ rm -rf cayoperico-temp                 │
  └──────────────────────────────────────────┘

  ✅ 完了！


┌────────────────────────────────────────────────────────────────────┐
│  方法2: ZIPファイル（Git不要）                                        │
└────────────────────────────────────────────────────────────────────┘

  ① GitHubにアクセス
     https://github.com/Torakinn/-
     
  ② [Code] ボタンをクリック
     ┌─────────────┐
     │ < > Code ▼  │ ← ここをクリック
     └─────────────┘
     
  ③ [Download ZIP] を選択
     ┌─────────────────────┐
     │ 📦 Download ZIP     │ ← これをクリック
     └─────────────────────┘
     
  ④ ZIPファイルを解凍
     -.zip → 右クリック → すべて展開
     
  ⑤ qb-cayoperico フォルダをコピー
     解凍したフォルダ内の "qb-cayoperico" を
     → resources/[qb]/ にコピー

  ✅ 完了！


┌────────────────────────────────────────────────────────────────────┐
│  方法3: GitHub Desktop（GUIで簡単）                                  │
└────────────────────────────────────────────────────────────────────┘

  ① GitHub Desktop をインストール
     https://desktop.github.com/
     
  ② アプリを開いて Clone
     File → Clone Repository
     
  ③ URL を入力
     https://github.com/Torakinn/-
     
  ④ フォルダをコピー
     クローンした中の qb-cayoperico を
     → resources/[qb]/ にコピー

  ✅ 完了！


╔════════════════════════════════════════════════════════════════════╗
║  インストール後                                                      ║
╚════════════════════════════════════════════════════════════════════╝

  📁 ファイル配置の確認
  
  resources/
  └── [qb]/
      └── qb-cayoperico/
          ├── fxmanifest.lua  ← これがあればOK！
          ├── config.lua
          ├── server/
          ├── client/
          ├── html/
          └── locales/


  ⚙️ 設定ファイルの編集

  1. server.cfg に追加:
     ┌────────────────────────────┐
     │ ensure qb-cayoperico       │
     └────────────────────────────┘

  2. ox_inventory/data/items.lua にアイテムを追加
     （詳細は README.md を参照）


  🚀 サーバー再起動

  ┌────────────────────────────┐
  │ サーバーを完全に再起動      │
  └────────────────────────────┘


  🎮 ゲーム内でテスト

  座標に移動: X: 1273.0, Y: -1720.77, Z: 54.77
  ox_target のインタラクションが表示されます


╔════════════════════════════════════════════════════════════════════╗
║  トラブルシューティング                                               ║
╚════════════════════════════════════════════════════════════════════╝

  ❌ リソースが起動しない
     → サーバーコンソールで: ensure qb-cayoperico
     → 依存関係を確認

  ❌ アイテムが表示されない
     → サーバーを完全に再起動
     → items.lua の構文エラーを確認

  ❌ ox_target が動作しない
     → ox_lib と ox_target を再起動
     → 最新版か確認
