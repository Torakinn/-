# QB-CayoPerico - カヨ・ペリコ強盗スクリプト

FiveM用のQB-Coreベースのカヨ・ペリコ大型強盗スクリプト。
ox_inventory、ox_target、ox_libを使用した完全な日本語対応の強盗システムです。

## 📋 機能

### 基本機能
- **複数侵入ルート**: メインゲート、排水トンネル、エアフィールド、ビーチの4つのルート
- **3種類のハッキングシステム**: セキュリティ（簡単）、ドア（中程度）、金庫（難しい）
- **NPC ガードシステム**: 10-15人のガード、パトロールルート、警戒レベル
- **報酬システム**: ランダム生成されるメインターゲットと複数の副次ターゲット
- **警察システム**: 自動通報、最小警察官数要件
- **チームプレイ**: 4-6人のプレイヤー推奨
- **60分のクールダウン**: 同一プレイヤーの連続実行を防止

### ハッキングシステム

#### 1. セキュリティハック（簡単）
- スキルチェック方式
- カメラ無効化
- 失敗時: 1分間ロックアウト

#### 2. ドアハック（中程度）
- 記憶ゲーム方式
- セキュリティドア開錠
- 失敗時: 警報発動の可能性

#### 3. 金庫室ハック（難しい）
- 指紋認証システム
- 制限時間: 90秒
- 失敗時: 追加ペナルティ時間

### 報酬

#### メインターゲット（ランダム生成）
| ターゲット | 報酬額 | 出現確率 |
|----------|-------|---------|
| ピンクダイヤモンド | $2,000,000 - $2,500,000 | 10% |
| 黒豹の像 | $1,800,000 - $2,200,000 | 15% |
| 債券 | $1,500,000 - $1,800,000 | 35% |
| 麻薬 | $1,200,000 - $1,500,000 | 40% |

#### 副次ターゲット（複数回収可能）
- **金の延べ棒**: $200,000-$300,000
- **絵画**: $150,000-$250,000
- **コカイン**: $100,000-$150,000
- **現金**: $50,000-$100,000

#### ボーナス
- **ステルスボーナス**: 発見されずに完了した場合、報酬の10%追加

## 🚀 インストール

### 必須要件
- FiveM Server (最新推奨)
- [QBCore Framework](https://github.com/qbcore-framework/qb-core)
- [ox_lib](https://github.com/overextended/ox_lib)
- [ox_inventory](https://github.com/overextended/ox_inventory)
- [ox_target](https://github.com/overextended/ox_target)
- [PolyZone](https://github.com/mkafrin/PolyZone)
- [oxmysql](https://github.com/overextended/oxmysql)

### セットアップ手順

1. **リソースのダウンロード**
   ```bash
   cd resources
   git clone https://github.com/yourusername/qb-cayoperico.git
   ```

2. **server.cfgに追加**
   ```cfg
   ensure qb-core
   ensure ox_lib
   ensure ox_inventory
   ensure ox_target
   ensure PolyZone
   ensure oxmysql
   ensure qb-cayoperico
   ```

3. **アイテムの追加**
   
   `ox_inventory/data/items.lua` に以下を追加:
   ```lua
   ['hacking_device'] = {
       label = 'ハッキングデバイス',
       weight = 500,
       stack = true,
       close = true,
       description = 'セキュリティシステムをハックするためのデバイス'
   },
   ['thermite'] = {
       label = 'サーマイト',
       weight = 1000,
       stack = true,
       close = true,
       description = 'ドアを破壊するための爆薬'
   },
   ['drill'] = {
       label = 'ドリル',
       weight = 3000,
       stack = false,
       close = true,
       description = '金庫を開けるための電動ドリル'
   },
   ['keycard'] = {
       label = 'セキュリティキーカード',
       weight = 50,
       stack = true,
       close = true,
       description = 'セキュリティドアを開けるためのキーカード'
   },
   ['bolt_cutters'] = {
       label = 'ボルトカッター',
       weight = 2000,
       stack = false,
       close = true,
       description = 'フェンスや鎖を切断するための工具'
   },
   ```

4. **設定のカスタマイズ**
   
   `config.lua` を編集して、報酬額、プレイヤー数、クールダウンなどを調整できます。

## 🎮 使い方

### 強盗の開始

1. **準備エリアに移動**
   - 座標: `1273.0, -1720.77, 54.77` (マイルハイクラブ付近)
   - ox_targetで相互作用ポイントが表示されます

2. **必要アイテムを確認**
   - hacking_device
   - thermite
   - drill
   - keycard

3. **チームを編成**
   - 4-6人のプレイヤーが必要
   - リーダーが強盗を開始

4. **侵入ルートを選択**
   - メインゲート: 高難易度、正面突破
   - 排水トンネル: ステルス推奨
   - エアフィールド: ヘリコプター降下
   - ビーチ: ボート上陸、容易

### 強盗のフェーズ

#### フェーズ1: 準備
- チーム集合
- 装備確認
- ルート選択

#### フェーズ2: 侵入
- 選択したルートで島に移動
- ガードを回避または排除
- ステルス or 強襲

#### フェーズ3: セキュリティ突破
- カメラシステムのハッキング
- セキュリティドアの開錠
- ガードのパトロール回避

#### フェーズ4: 金庫室
- 金庫室ドアのハッキング
- ドリルで金庫を開錠
- メインターゲットと副次ターゲットを回収

#### フェーズ5: 脱出
- 脱出ポイントに移動
- 警察から逃走
- 報酬の受け取り

## ⚙️ 設定

### config.lua の主要設定

```lua
Config.MinPlayers = 4          -- 最小プレイヤー数
Config.MaxPlayers = 6          -- 最大プレイヤー数
Config.MinCops = 4             -- 必要な警察官数
Config.Cooldown = 3600000      -- クールダウン時間（ミリ秒）
Config.Debug = false           -- デバッグモード
```

### 報酬のカスタマイズ

`Config.MainTargets` と `Config.SecondaryTargets` で報酬額と出現確率を調整できます。

### ガードのカスタマイズ

`Config.GuardSpawns` でガードの配置、武器、パトロールルートを設定できます。

## 🔒 警察システム

- 金庫室に侵入すると自動的に警察に通報されます
- 最小4人の警察官がオンラインでないと強盗を開始できません
- QBCoreのディスパッチシステムと連携します

## 🐛 トラブルシューティング

### よくある問題

**Q: 強盗が開始できない**
- 必要なアイテムを持っているか確認
- 4人以上の警察官がオンラインか確認
- クールダウン中でないか確認

**Q: ハッキングミニゲームが表示されない**
- F8コンソールでエラーを確認
- ox_libが正しくインストールされているか確認

**Q: ガードがスポーンしない**
- サーバーのリソース制限を確認
- デバッグモードを有効にして確認
