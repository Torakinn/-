## 🚀 使用方法

### インストール
1. `resources/[qb]/qb-cayoperico/` に配置
2. `server.cfg` に `ensure qb-cayoperico` を追加
3. アイテムを ox_inventory に追加（README参照）
4. サーバー再起動

### 開始方法
1. 座標 `1273.0, -1720.77, 54.77` に移動
2. ox_target でインタラクト
3. チームを編成（4-6人）
4. 侵入ルートを選択
5. 強盗を実行
