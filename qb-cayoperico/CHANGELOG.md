# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-02-12

### Added
- 初回リリース
- QB-Core フレームワーク統合
- ox_inventory、ox_target、ox_lib サポート
- 4つの侵入ルート（メインゲート、排水トンネル、エアフィールド、ビーチ）
- 3種類のハッキングシステム
  - セキュリティハック（簡単）- スキルチェック
  - ドアハック（中程度）- 記憶ゲーム
  - 金庫ハック（難しい）- 指紋認証
- NPC ガードシステム
  - 15体のガードスポーン
  - パトロールルート
  - 警戒システム
  - 増援システム
- 報酬システム
  - 4種類のメインターゲット（ランダム生成）
  - 4種類の副次ターゲット
  - 自動報酬分配
  - ステルスボーナス（10%）
- 警察システム
  - 最小警察官数チェック（4人）
  - 自動通報
  - ディスパッチ連携
- 5フェーズ強盗構造
  - フェーズ1: 準備
  - フェーズ2: 侵入
  - フェーズ3: セキュリティ突破
  - フェーズ4: 金庫室
  - フェーズ5: 脱出
- チームプレイシステム（4-6人）
- 60分クールダウンシステム
- HTMLベースのハッキングUI
- 完全な日本語ロケール対応
- 包括的なドキュメント

### Security
- サーバー側アイテム検証
- クールダウン管理
- 不正防止チェック

### Performance
- 最適化されたNPCスポーン
- イベントベースのアーキテクチャ
- 効率的なスレッド管理
