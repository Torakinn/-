## 実装された主要機能

### 1. フレームワーク統合 ✅
- **QB-Core**: 完全統合
- **ox_lib**: プログレスバー、スキルチェック、メニューシステム
- **ox_inventory**: アイテム管理
- **ox_target**: インタラクションゾーン
- **PolyZone**: エリア検知

### 2. 侵入ルートシステム ✅
4つの異なる侵入ルートを実装：
- **メインゲート** (4974.0, -5166.0, 2.5)
- **排水トンネル** (5044.0, -5815.0, -10.0)
- **エアフィールド** (4503.0, -4526.0, 4.0)
- **ビーチ** (5010.0, -5750.0, 15.0)

### 3. ハッキングシステム ✅
3種類のハッキングミニゲーム：

#### セキュリティハック（簡単）
- ox_lib スキルチェック使用
- 難易度: easy x 3
- 制限時間: 30秒
- 失敗ペナルティ: 60秒ロックアウト

#### ドアハック（中程度）
- メモリーゲーム（記憶ゲーム）
- 難易度: easy, medium x 2
- 制限時間: 45秒
- 失敗時: 50%で警報発動

#### 金庫ハック（難しい）
- 指紋認証システム
- 難易度: medium, hard x 3
- 制限時間: 90秒
- 失敗ペナルティ: 120秒 + 30秒追加

### 4. NPCガードシステム ✅
- **スポーン数**: 15体のガード
- **配置場所**: メインゲート、コンパウンド、エアフィールド、ビーチ
- **パトロール**: 2つのパトロールルート実装
- **警戒システム**: 
  - 検知範囲: 30m
  - 視線チェック: 15m以内
  - 警戒時: 全ガードが戦闘モード
- **増援システム**: 30秒後に3-5体の増援

### 5. 報酬システム ✅

#### メインターゲット（ランダム生成）
```lua
ピンクダイヤモンド: $2,000,000-$2,500,000 (10%)
黒豹の像:         $1,800,000-$2,200,000 (15%)
債券:             $1,500,000-$1,800,000 (35%)
麻薬:             $1,200,000-$1,500,000 (40%)
```

#### 副次ターゲット
```lua
金の延べ棒: $200,000-$300,000 (2箇所)
絵画:       $150,000-$250,000 (3箇所)
コカイン:   $100,000-$150,000 (2箇所)
現金:       $50,000-$100,000  (3箇所)
```

#### 報酬分配
- リーダー: 40%
- メンバー: 残り60%を均等分配
- ステルスボーナス: 総報酬の10%追加

### 6. 警察システム ✅
- **開始要件**: 4人以上の警察官がオンライン
- **自動通報**: 金庫室突入時
- **ディスパッチ**: QBCore dispatch連携
- **ブリップ**: 島の位置を2分間表示

### 7. プレイヤー要件 ✅
- **最小人数**: 4人
- **最大人数**: 6人
- **必須アイテム**:

  - thermite

## インストール手順

1. **依存関係の確認**
   ```bash
   qb-core
   ox_lib
   ox_inventory
   ox_target
   PolyZone
   oxmysql
   ```

2. **リソースの配置**
   ```bash
   resources/[qb]/qb-cayoperico/
   ```

3. **server.cfgに追加**
   ```cfg
   ensure qb-cayoperico
   ```

4. **アイテムの追加**
   README.mdの指示に従ってox_inventoryにアイテムを追加

5. **サーバー再起動**

## 既知の制限事項

1. **島の座標**: デフォルトのカヨ・ペリコ座標を使用。カスタムマップには対応していません。
2. **同時実行**: 複数のチームが同時に強盗を実行すると、ガードが干渉する可能性があります。
3. **ネットワーク同期**: 高レイテンシー環境では、ガードの動作が不安定になる可能性があります。
